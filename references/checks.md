# 脚本检查项口径

`style_lint.py` 各检查项的判法与改法。行为合同的单一来源是 `../SKILL.md`，本文件是它的细则。

## 报告怎么读

严禁项非 0 或限量项超门禁 → 退出码 1；源文件、基线或词表缺失、族名写错 → 退出码 2。
逐处清单写进 `--report`，摘要打印到 stdout。docx 的行号是正文层段落序号，
表格单元格记作「表2 r3c4」；表格、图题与表注只做用词与术语检查，不进密度统计。

脚本分三类输出：**门禁**（超人写 p99 或计 0 即判，决定退出码）；**告警**（A/V/T/C/P 级与可读性 A13～A15，逐处列出，按上下文判）；
**B 级分布偏离**（双边比对人写 p10~p95，低于下限记过净，高于上限记过密，≥4 项才值得回填）。重复片段、长句、句长变异系数只统计。
各检查项的写法口径见下文。**门禁数值以报告表头为准**，它随 `--baseline` 变化；分位数表见 `human-baseline.md`，本文件不抄数值。
逻辑断层、无主语病句、脚本词表之外的新造黑话、学科专有的同义换名、名词串与读者层次错位，脚本查不了，靠本技能的审查环节判。

**不要把脚本当清零器**：人写论文里一字线、弯引号、正文冒号都是常态，把它们全删只会把稿子洗成
标点贫乏、句长均匀、全靠连词推进的机器腔，反而更像 AI。脚本判的是密度越界，不是符号存在。

## 标点、数值书写与交叉引用（脚本 F、A3、L1、C4、C6）

以下各项除注明"计 0 即判"外都按密度判，个别一处不动它；数值区间、数学负号、标准编号里的横线，
标准代号、物理单位里的斜杠都是豁免项，不必改。

- **一字线与破折号（F1）**：—、–、−、－ 不作概念串联用（视觉/触觉—两条路线 → 视觉与触觉两条路线）。
  插入语式破折号改成两句，或用逗号收在句尾，或用"即"字引导。标准编号（GB/T 7714—2015）、
  数值区间（20—30 mm）与数学负号豁免。
- **双引号（F3）**：引原文改间接引述，出处交给引用标记；专业术语直接书写，不靠引号强调。出现一两处属正常，不必清零。
- **书名号《》（F8）**：专著、教材与软件系统直接平叙写名称全称，出处交给引用标记（如 [15]）。多数人写论文一处也没有。
  两类豁免：法规、规划、意见一类文件名按 GB/T 15834 必须用书名号；标准正式名称在编号或「国家标准」一类限定语之后加
  书名号（如 GB/T 7714—2015《信息与文献 参考文献著录规则》）是 GB/T 1.1 的规范写法，脚本定性为 标准名称，
  同样不计密度。平叙写法（GB/T 7714—2015 参考文献著录标准）也正确，两者不必互改。
- **多位数分节（F9）**：四位以上数值**一律写 1200，不写 1 200**。国标两种都允许，本技能取不分节：千分空在 Markdown 里
  会被误读成两个数，也可能在行末把数值拆到两行。目标刊要求分节时用 `--num-group=grouped` 切换。
  代号、序号、年份一律不分节：GB/T 7714—2015、1994年、编号1987号，写成 GB/T 7 714、1 994年、1 987号即违规。
- **量值的两处间隔（F10）**：**只有数值与计量单位之间留空，汉字与数值一律贴合**——`下游6～8 m处`、`试样长度1200 mm`、`转速500 r/min`。
  不带单位的年份、百分数、计数同样贴合：`较2000年增长约122%`、`第1章`，不写 `较 2000 年增长约 122 %`；百分号紧跟数字。
  前者是 GB 3101 的规定；后者国标不作规定，取贴合是为了避免手打空格宽窄不一，排版引擎会自动插入四分之一空。
  目标刊另有要求时用 `--unit-space` 与 `--qty-lead` 切换。
- **数值范围用全角浪纹线 ～（F11）**：半角 ~ 不是国标连接号（GB/T 15834 4.13.2），一律判违规。
  写作 `25～30 g`：数值与浪纹线之间不留空，数值与单位之间留空；前一数值的单位可省略（`5～100 公斤`）。
  F9～F11 的标准依据见 `human-baseline.md` 第四节，改写示例见 `replacements.md` 第十节。
- **斜杠不作概念串联（F2）**：二维/三维 → 二维与三维；精度/速度 → 精度与速度。
  标准代号（GB/T、ISO/IEC）、物理单位（m/min、m/s）、分数比例与英文串联豁免，中文并列替代按密度判。
  这五类之外的其他斜杠计 0 即判——命中时先确认脚本没把新型用法误分类，再动手改。
- **冒号（F7，清单冒号即 A3）**：正文叙述里用冒号引出机械清单或从句（涉及：光照、纹理、噪声；主要包括：……）改为平叙；
  比例时间（3:1、08:30）与公式引出豁免。正文冒号低于人写 p10 反而是过净信号（B 级报出），
  说明稿子被洗得不像人写，不要为了"清零"把正常的解释性冒号全改掉。
- **章节回指默认不写（脚本 C4，门禁）**：人写论文正文基本不回指节号，结构路线图单独成句放在引言末尾
  （本文结构安排如下：第1节…；第2节…）。正文里要衔接前文时复述内容，
  不给编号：「2.1节与2.2节的方法均假设…」→「前述小目标检测与小样本学习方法都默认…」。
  **不要把句末的「（2.1节）」升格成主语或宾语**（「促成了第3节关于…的探讨」「与2.2.4节相呼应」），
  那只是把指针挪进主干，读者照样要回翻；先删，删后句意不全再复述内容。只有读者确需回查公式、参数或定义时
  才保留，写成状语「如2.3节所述」或「见2.3节」，不作主语，不放段首。
  脚本按全文密度进门禁，报告逐条列出段首句带节号与一句 ≥2 处回指的句子，路线图句不列。
- **图表引述融入句子（脚本 C6，计 0 即判）**：图表作主语（"表1系统对比了各模型的结构参数"）或谓语主干
  （"系统整体拓扑结构如图3所示"），不要挂在句末的批注式括号。括号内容以图表号开头、含「见/如＋图表号」
  或以图表号收尾即判，如 `（图3）`、`（见表1）`、`（如图2(a)所示）`、`（R=0.019，见图4(c)）`；
  括号里只是顺带提到图表的说明语（与图1(c)中标记的面）不计。人写语料约 29% 的论文出现过，
  这是本 skill 的书写口径，不按基线放行。
- **括号仅用于合法辅助用途**：专业术语首次给出的外文全称及缩写（如卷积神经网络（CNN））、特定分类行业通俗同义词以及数学公式参数（如 $(x, y)$）。
- **分号（L1）**：按全文密度与单段峰值判。分号本身不是 AI 特征，用分号串起 4 项以上无层次的并列才是，按内容改，不按计数改。
- 中文正文统一全角标点。

## 可复算的 AI 腔特征（脚本 A 级）

**计 0 即判**：
- **A1 隐形字符**：零宽空格与零宽连字（U+200B–U+200D）、双向控制符、软连字符 U+00AD、Unicode 私有区（U+E000–U+F8FF）一律清除。这类字符来自模型输出或网页复制，检测器与查重系统都会命中。
- **F6 英文摘要里混入的中文标点**。非并列类斜杠见上文 F2。

**按密度进门禁**：
- **A7 无引用泛权威**："研究表明""众所周知""业界普遍认为""大量研究"的断言，前后一句内必须落到具体文献引用标记或本文自身的实验证据，否则删掉整句权威口吻，直接陈述事实。脚本查断言左 25 字与右 40 字，两侧都无引标才计入（`{{key}}`、[12]、[5,19,22]、(2019) 与 `[待补引]` 都算引标）。
  "有观察指出""有学者认为""某某理论认为"这类匿名归因、以学派或学科作主语的归因，脚本不查，按 `ai-tells.md` 第 10 条人工判：落到具体作者、文献与可核对的内容，补不出来源就标 `[待补引]`，严禁凭记忆编造引文。
- A3 空转冒号见上文"冒号"。

**告警（按上下文判，不强制改）**：
- **A2 段首零回指**：段落首句以"这/该/此/其/上述"开头却没有先行词时，回填被指代的名词。
- **A4 句尾空转挂尾**："为后续研究提供了参考""具有重要的理论意义与应用价值""为……奠定了基础"式收尾，删掉或替换成具体结论。
- **A5 虚动词名词化**："进行分析""实现提升""开展评估"改为"分析""提升""评估"等实义动词直述。
- **A6 弱谓词密度**：是、为、具有、存在、属于、成为占比过高时，说明句子在绕开动作，换成描述真实动作或机理的谓词。
- **A8 顿号链**：单个小句顿号成员 ≥6 个时拆句或分组，不要一口气罗列。
- **A9 连词密度**：和、与、以及、并且、同时、因此、从而堆叠会让文本机械均匀，靠语序与语义衔接替代显式连词。
- **A10 相邻句实词重合**：相邻两句字二元组 Jaccard ≥0.70 属同义反复，删一留一，保留带数据的那句。
- A12 并列悬空见 SKILL.md「段内论证链」；A13～A15 见 SKILL.md「四、可读性审查」。

## 术语与中文句式（脚本 T/C/P）

- **T1 缩写首现**：全大写缩写首次出现没给全称、全称晚于首现、重复定义、两处全称不一致。
  标准代号（GB、ISO、IEEE）与 DOI、ISBN 一类通用缩写免定义；YOLO 这类约定俗成的模型名是否要展开
  听目标刊，免定义的用 `--abbr-known` 追加。
- **T2 术语变体**：同一组写法在同一稿件并用（召回率/查全率、阈值/阀值、时延/延迟）。
  内置组在 `scripts/terms.tsv`，只收跨学科确属同义的写法；学科专有的写进稿件自己的 tsv。
  统一到规范写法，但引文原题名与参考文献不改。
- **C1 的字链**：一个小句里 ≥3 个结构助词「的」，拆出一个定语改成动宾或主谓。偶发不改。
- **C2 递进堆叠**：「不仅……而且……更……」「既……又……还……」一句三层递进，删到两层或拆句。
- **C3 等长排比**：同一句里 ≥3 个 3～8 字的等长短句连排（精度更高，速度更快，成本更低），
  改成一个带数据的主句加补充。
- **C5 压缩句（门禁）**：≥50 字且一个结构助词「的」都没有的句子，占全部 ≥50 字句的比例超人写 p99 即不通过
  （人写约占 5%）；「的」密度低于人写 p05 另提示，明显偏少时读者会觉得句子「浓缩」。标 [数值] 的是含 ≥3 个数的参数报告句，
  人写也常这样写，多可保留；其余按 SKILL.md「一、润色」的「段首句与压缩句」拆句、补「的」。
- **P 待补引**：`[待补引]` 占位在 A7 里视同已落引用，避免补引前反复报错；报告逐处列出，投稿前必须清零。
- C4 节号回指、C6 图表括注见上文"标点、数值书写与交叉引用"。

阈值均可由命令行覆盖：`--dun-max`、`--overlap`、`--cv-min`、`--long-sent`、`--fam-para-min`、
`--fam-para-max`、`--fam-span`、`--colon-k`、`--quote-k`、`--dash-k`、`--slash-k`、`--book-k`、
`--auth-k`、`--semi-k`、`--secref-k`、`--nde-long`、`--opener-min`。不给时取 `--baseline` 指定的基线 p99（段首立论率取 p10），
改之前先读 `human-baseline.md`。
可读性词表可由 `--known-terms`（逗号分隔，目标读者已熟悉、不必解释的术语）与 `--terms-file`（每行一个，追加本文领域术语）调整。
