# 可读性病例库（"说人话"审查）

病例取自工程类中文综述润色中反复出现的写法，已改写为不涉及具体课题的通用示例。
这类句子的共同点是：用词合法、标点合规、句长正常，脚本门禁照样判"通过"，
毛病出在读者要不要猜。审查时拿这里的病因对照，不要只看脚本结论。

判定标准只有一条：**目标读者读到这里，能否不查资料、不回翻前文就知道这句在说什么。**
目标读者由任务指定；未指定时按"本领域工科研究生，不默认熟悉相邻学科的理论术语"处理。

## 一、压缩简称与行话（脚本 A13）

把一个过程或一组对象压成两三个字，作者自己熟悉，读者要反推。

| 原句 | 改句 | 病因 |
|---|---|---|
| 滑窗步长过小则抬高窗口数与时延 | 滑窗步长过小会增加窗口数量，拉长单幅图像的推理耗时 | "时延"看不出指哪一段时间；一个"抬高"管两个宾语 |
| 各分支结果经非极大值抑制归并后输出 | 各分支的检测框先统一到同一坐标系，再经非极大值抑制剔除重复框后输出 | "归并"不说做了什么；展开后才看出须先统一坐标 |
| 该工作属于在线标定的期刊实例 | 该工作实现了在线标定 | "期刊实例"是审稿批注腔，出处已由引用标记承担 |
| 各数据集的标注粒度差异较大 | 各数据集有的只给图像级类别标签，有的标注到像素级 | "粒度"要读者自己猜是哪一级 |
| 全量精标注成本过高 | 对全部样本做像素级精细标注成本过高 | "全量""精标注"是口头简称 |
| 根因在于…… | 问题的根源在于…… | "根因"是运维术语简称 |
| 光机电误差应分别补偿 | 光学、机械与电气三类误差应分别补偿 | 拼缩词要读者自己拆开 |
| 而非一般性提精度手段 | 不宜作为一般性的精度提升手段 | 口语简称 |

改法：把压缩词还原成"对什么、做了什么"。还原后常会暴露原句的事实或逻辑错误（例如处理顺序写反、对象写错），这是这类病例最大的价值。

## 二、理论术语未解释（脚本 A14）

术语本身准确，但读者层次不需要、或第一次出现时没有交代它具体做什么。

| 原句 | 改句 | 病因 |
|---|---|---|
| 样本不足时，经验风险与真实风险的偏离无法由数据自身约束，必须引入额外先验 | 有效训练样本不足时，仅靠训练数据难以学到真实分布，模型的泛化能力无法保证，因此必须从数据之外引入先验 | 统计学习理论概念，综述读者不需要这一层，给结论即可 |
| 先验可取自源域模型与结构假设 | 先验可取自预训练模型与特征结构约束 | "源域""结构假设"两个抽象术语压成一个短语 |
| 重采样在数据层面提高少数类的出现频次，损失重加权在目标函数层面提高其梯度贡献 | 一类做法是重采样，即训练时重复抽取少数类样本，使各类样本数量趋于均衡；另一类是损失重加权，即加大少数类在损失函数中的权重，使模型误判这些类别时受到更重的惩罚 | 术语接术语，没有一个说清具体动作；"梯度贡献"要懂反向传播 |
| 该标签分配策略作用于正样本划分 | 在决定哪些预测框参与训练时，该策略为少数类分配更多正样本 | 名词串代替了动作 |

改法：术语保留（审稿人会检索它），第一次出现时紧跟"即……"写明它对数据或模型做了什么；
理论推导层面的术语，读者层次不需要就换成结论。

## 三、抽象名词当主语去做动作（脚本 A15）

主语是"先验、本质、需求、特性"一类抽象名词，谓语却是"转向、推动、导向、催生"一类施事动作。
语法通顺，读者却要自己补出"谁"在做。

| 原句 | 改句 |
|---|---|
| 当真实样本无法增加时，先验转向类别权重与损失设计 | 当真实样本无法增加时，可转而在类别权重与损失设计中引入先验 |
| 标注稀缺本质导向弱监督学习 | 像素级标注难以获得，因此多数工作改用只需图像级标签的弱监督学习 |
| 精度需求倒逼传感器升级 | 为满足0.01 mm的测量精度，系统须改用分辨率更高的传感器 |

改法：把抽象名词还原成它描述的事实（"像素级标注难以获得"），再让真正的动作发出者做主语，
或改成"使/需要/因此"一类因果结构。

## 四、名词串与多义组合（脚本不查，只能人读）

脚本试过按"的/与"个数与小句长度判名词串，病例与改句分不开，且人写论文里
"提出了一种基于……的……网络"极常见，故未收入脚本。审查时逐句看：

- 长名词串代替动作：「设计多尺度注意力引导的自适应特征重标定融合模块」→ 拆成"做什么 + 目的"的动宾句，如"设计一个融合模块，用注意力权重对不同尺度的特征重新加权"。
- 相邻两词被读成一个词：「两项工作报告的均为离线指标」被读成"工作报告"；「推理耗时尚未公开」被读成"时尚"。改法是调换语序或换动词（"两项研究给出的均为离线指标"）。
- 一词管两宾且搭配不一：「抬高窗口数与时延」「该方法的成本与精度须经现场复测确认」（成本不需要复测确认）。

## 五、读者层次错位（只能人读）

- 批注腔进正文：「但该文未说明精度按何种口径统计」「另在 4.2 节讨论」「如后续 4.2 节所示」。
  口径问题交给表注或统一说明，章节回指改为按内容回指（"前述的……方法"）。
- 离题收尾：段末补一句与本段主题无关的"另一维度问题留待后文"，删去，过渡交给下一节首句。
